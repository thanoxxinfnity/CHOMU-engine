// the engine

Make games on your phone.

CHoMU Engine is a branded Android build of the full Godot 4.7.2 editor. Open, edit and run 2D & 3D projects right on an Android device — no PC needed.

⚙️

Full editor on Android

Scene tree, inspector, script editor, project manager and run button — the complete Godot 4.7.2 editor compiled for arm64 Android.

📜

GDScript support

Write gameplay in GDScript with the built-in code editor. Projects stay compatible with standard Godot 4.7.

🧊

2D & 3D renderers

Forward+, Mobile and Compatibility renderers included, plus all standard engine modules.

📦

Open Chomu projects

Import the Chomu City project (source on GitHub) and tweak the city, cars and shaders yourself.
